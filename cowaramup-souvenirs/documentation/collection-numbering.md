# Cowaramup Cow Collection - numbering system

Every collectible carries its series number where a collector finds it: debossed under the base
(or under the figure on bases-free items), never on the display face.

```
COWARAMUP COWS
01  CLASSIC        (CRW-003 Deluxe - implemented)
02  FARMER         (planned CRW-B02: hat, fence, farm sign)
03  SURFER         (planned CRW-B04: surfboard with fins, wave, sand base)
04  AUSSIE         (planned CRW-B03: hat, native plant, WA sign)
05  WINE COUNTRY   (planned CRW-B06: bottle with capsule + label, glass, vines)
06  BEACH          (planned CRW-B05)
07  CAMPER         (planned CRW-B10)
08  CHRISTMAS      (planned CRW-B08)
```

Underside text block (debossed, mirrored so it reads when the piece is turned over):

```
NN  NAME
COWARAMUP  WA
CRW-XXX
```

Family rules, so the series reads as one collection:

- Same Cowa head: eyes, lids, muzzle, smile, horn shape, and the signature patch over the right eye.
- Same Paddock base: pebble outline, grass tufts, front lettering, and COW TOWN WA on the back.
- Each cow is individual through pose, head angle, ear set, expression, accessory and the tool-4 story colour.
- Its number is on the base only; the ear tag carries the story colour.
