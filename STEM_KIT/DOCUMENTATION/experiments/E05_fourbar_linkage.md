# Experiment E05 — Turning circles into swings

**Kit:** Linkage lab (Kit 10) · **Levels:** Explorer (watch & draw), Engineer (angles, Grashof), Inventor (coupler curves, design)

## Question
When the crank goes round and round, how far does the rocker swing — and can
you change it?

## Prediction
Crank 20 mm, coupler 50 mm, rocker 40 mm, ground 60 mm. The rocker swings
about ____ degrees.

## Build
Assembly guide 05. Ground pivots at plate holes A (25, 35) and B (85, 35).
Tighten pivots until snug, then back off a quarter turn — links must swing
freely.

## Experiment
1. Turn the knob slowly; tape a protractor (or print one) under the rocker
   and read its two end angles.
2. Move ground pivot B to x = 75 (ground 50) and x = 65 (ground 40). Repeat.
3. Tape a pencil through a coupler hole (any of the six) onto paper under
   the mechanism. Draw the coupler curve for three different holes.

## Measure

| Ground (mm) | Rocker min angle | Rocker max angle | Swing | Does the crank go all the way round? | Feels smooth / jerky |
|---|---|---|---|---|---|
| 60 | | | | | |
| 50 | | | | | |
| 40 | | | | | |

(The CAD check gives 60° of swing and a smooth 51°–125° transmission angle for the 60 mm ground.)

## Explain
**Grashof's rule:** if shortest + longest ≤ the sum of the other two links,
the shortest link can turn fully. Here 20 + 60 ≤ 50 + 40, so the crank goes
round. The *transmission angle* (between coupler and rocker) tells you how
well the coupler can push: near 90° is easy, near 0° or 180° the linkage
jams or jerks. With a 40 mm ground it dips to 22° — feel the difference!

## Build it wrong on purpose
Make the crank 50 mm (6-hole link) and the coupler 20 mm. What happens? Which
link is now the shortest? Does Grashof's rule still let the crank turn?

## Challenge
Design a linkage whose coupler point draws a shape like a foot stepping
(flat along the bottom, lifting at the end) — the start of a walking robot.
